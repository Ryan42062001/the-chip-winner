# Retired Workflow V3/V4 History

This directory preserves the pre–Speed Workflow V2.1 governance system for traceability.

It contains the former role directories, task registry, Manager/Auditor/Builder handoffs, audit packets, evidence records, Workflow V3.x documents, and workflow-specific automation/tests exactly as they existed on canonical master at migration baseline `e9159492c7c4218cc7b5126a3f586620a3dab344`.

These files are **historical evidence only**. They are not active instructions, workflow authority, assignment state, merge authority, or release gates.

Open historical PRs remain independently preserved in GitHub. In particular, Trade Winner PR #147 is retained as source evidence for the new V2.1 Trade Winner phase rather than merged directly.
