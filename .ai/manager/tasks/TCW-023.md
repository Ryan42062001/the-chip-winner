## OBJECTIVE

Implement the accepted TCW-022 Trade Analyzer v1 strategy contract as a production, read-only team-consequence analyzer answering:

> What happens to my fantasy team if I make this proposed trade, and why?

## ACCEPTED IMPLEMENTATION

Builder implemented the bounded v1 feature through PR #109 without modifying the accepted Strategy contract or `config/field-validation.json`.

Production scope includes:
- multi-player and unequal-count hypothetical proposals;
- direct/resolved post-trade roster construction;
- explicit follow-up drops for known roster-rule pressure;
- pre/post best legal lineup consequence rather than package arithmetic;
- starter/FLEX versus bench consequence;
- current-week lock/kickoff qualification;
- listed-position depth plus legal contingency/fragility;
- latest-snapshot ESPN replacement context when available;
- known bye effects;
- complete-only future/playoff windows using mean-weekly materiality;
- source-separated projection evidence and disagreement handling;
- deterministic cross-horizon conclusion precedence;
- objective framing that does not mutate source facts;
- first-class Trade Analyzer UI and browser flow;
- explicit read-only semantics with no ESPN trade mutation path and no hidden trade/winner/confidence score.
